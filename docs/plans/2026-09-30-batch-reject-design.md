# 生命周期 7 批量自动拒绝核价

用户最终确认：设定次数（≥9）并启用一次后持续自动处理，刷新后恢复；不需要与提交核价互斥，不改第 1 个报价逻辑。

- 当前店铺全托/半托，默认阈值 9。首次安装未启用，点击一次启用后立即运行，每轮结束 1 分钟继续。
- 按店铺独立保存阈值、类型、启用状态；已启用时刷新 5 秒后恢复。
- 自动扫描待确认核价单，按 ID 去重并串行拒绝，不需要逐轮预览或确认；不修改标题。
- 停用取消后续轮次和未发出的单据；等待在途请求返回。异常暂停并展示结果。
- 只读共享店铺初始配置，日志向第 1 个现有面板发送；不修改 1-6 配置。
- 上游接口不变，版本 2026.0930.2 单独另存，稳定入口不变。
