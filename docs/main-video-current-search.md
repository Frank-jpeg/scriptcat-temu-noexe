# 商品主图视频批量更新 v1.5.1

本版修复旧版只传页码、不传网页搜索条件的问题。处理范围来自网页实际发送的分类、状态、货号、语言、商品 ID、任务类型、生成时间等查询参数，每页条数也沿用网页设置。

## 使用

1. 安装或更新后刷新 TEMU 图片/视频更新任务页面。
2. 网页选择“全部”，选择需要的商品分类，点击网页“查询”。
3. 打开右下角“商品视频”，确认已同步的分类、条数、每页条数和页数。
4. 选择并上传视频，等待视频就绪。“额外类目限制”通常留空。
5. 保持“仅预览，不提交”不勾选，点击“按当前搜索边扫边提交”。

每页的执行顺序是：读取商品 → 筛选并检查视频 → 立即提交该页缺视频的商品 → 读取下一页。不会等待全店或全部搜索结果扫描完成才开始提交。

“仅预览，不提交”默认关闭，手动勾选后仅查询，不要求先上传视频。需要同时补空缺详情视频时，再勾选对应选项。

## 搜索范围

- 选择“全部”不会强加“待更新”条件，处理的是所选分类下的全部搜索结果。
- 每次开始前自动重新触发网页查询，随后锁定本次参数；从第一页开始翻页，只修改页码。例如 8377 条、每页 20 条，对应 419 页。
- 网页查询通过 fetch 或 XMLHttpRequest 被动同步；脚本自己的分页请求不会覆盖网页搜索快照。
- 未选择分类、未捕获有效查询、查询失败或出现未支持的新参数时禁止启动，不退回全店扫描。
- 每个 SPU 还会核对自己的任务分类是否符合网页指定的类目层级。分类缺失、冲突或不符合时跳过。
- 运行中更改网页筛选或发起新查询、切换店铺或结果总数变化时，中止后续处理；已经提交的更新不会撤销。

## 视频与发布边界

- 同一次任务使用同一个上传视频；不会自动为不同商品匹配不同视频。
- 只补空项，已有视频即使显示“质量不佳”也不会替换。
- “成功”沿用接口返回判断，不代表前台已展示或审核通过。
- 刷新页面会清空本轮运行状态和清单。

稳定入口保持为根目录 `商品主图视频批量更新.user.js`，版本副本为 `versions/商品主图视频批量更新.1.5.1.user.js`，两者内容相同。仓库发布版恢复 `@updateURL` 和 `@downloadURL`，指向本仓库稳定入口。

从仓库安装的旧版本可通过脚本管理器检查更新。若此前安装的是关闭自动更新的本地独立版，应从仓库稳定入口重新安装一次。
